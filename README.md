## Quick Start (Local Development)

```bash
# 1. Install dependencies
npm install

# 2. Run frontend web dashboard (http://localhost:5173)
npm run dev:web

# 3. Run backend API server (http://localhost:3000 - optional)
npm run dev:api
```

## Key Modules & Capabilities

- 📊 **Executive Analytics & Attribution**: Universal multi-currency engine (USD, EUR, INR, GBP), ROAS, AOV, and Meta regional conversation pricing.
- 💬 **Live Shared Helpdesk Inbox**: Real-time 24h Meta customer care session indicator, agent assignment, internal notes, canned responses, and inbound simulator.
- 📱 **Template Studio**: Meta Cloud API template authoring with compliance verification and live **iPhone 16 Pro WhatsApp Preview** with verified FGSN branding.
- 🚀 **Broadcast Campaigns**: Outbound audience broadcasts with automated delivery & financial attribution estimators.
- ⚡ **Automated Workflows**: Visual trigger-based recovery workflows (abandoned cart, VIP loyalty, onboarding).
- 👥 **Customer CRM**: RFM segmentation, customer lifetime value, and order history.
- 📱 **100% Responsive Design**: Fluid across Desktop, Tablets (off-canvas drawer navigation), and Mobile phones.
